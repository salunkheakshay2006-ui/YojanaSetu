# YojanaSetu

## Autonomous Scheme-Bundle Optimizer for Citizens

YojanaSetu is an AI-assisted platform that helps citizens identify
potentially eligible government schemes and recommends compatible
scheme bundles based on their goals, benefits, documentation,
application effort, and conflicts.

## Problem

Citizens can find individual government schemes, but it is difficult
to determine which schemes can be applied for together, which schemes
conflict, which documents are missing, and what should be applied for first.

## Solution

YojanaSetu provides:

- Citizen profile analysis
- Government scheme discovery
- Eligibility reasoning
- Scheme conflict detection
- Scheme bundle optimization
- Missing document analysis
- Document prioritization
- Application checklist
- Explainable recommendations
- English / Hindi / Marathi explanations

## Key Innovation

Instead of simply listing government schemes, YojanaSetu creates
personalized, compatible and document-ready scheme bundles.

        ↓

        ↓

## Technology Stack

Frontend: React / Next.js
Backend: Python FastAPI
Database: SQLite / PostgreSQL
Rules: JSON + Python Rule Engine
Optimization: OR-Tools / Custom Weighted Scoring
AI: LLM for profile interpretation and explanations

the information provided. Final eligibility and approval depend on
the relevant government department and official scheme rules.
